# Manifests AEB

Mise à jour : 2026-07-27

Ces manifests rendent le Book exploitable par des outils de publication, de recherche, de génération PDF ou de RAG.

## Fichiers

- `volume-manifest.json` : volumes modulaires A-L.
- `adr-manifest.json` : ADR extraits en fichiers individuels.
- `index-manifest.json` : index spécialisés et artefacts de normalisation.
- `rag-manifest.json` : liste des documents ingérables avec politique de chunking recommandée.
- `manifest-summary.json` : synthèse des compteurs.
