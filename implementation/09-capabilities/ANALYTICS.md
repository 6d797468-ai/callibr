# CAP-14 — Analytics

Mise a jour : 2026-07-28

## Definition

Capacite de collecter, analyser et presenter des metriques d'apprentissage : scores, tendances, comparaisons.

## Stabilite

L'analytics est une capacite transversale. Les metriques evoluent, mais la capacite d'analyser reste.

## AEB Volumes Concernes

- B10 — Analytics, Learning Intelligence & Coaching Platform (ALICP)
- I11-I20 — Data Platform

## Criteres De Stabilite

Une feature analytics est terminee quand :

- Des metriques sont collectees automatiquement
- Les tendances sont calculables
- Les tests couvrent le calcul de metriques
